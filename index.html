AI agents for documentation drafting

Builder and sole maintainer · 3 products, 10 releases a year

Challenge

Drafting the documentation for a single feature took a writer about a week.

What I did

  • Built automation agents for release notes and feature documentation.
  • Developed orchestrated subagents and skills the whole team uses each release.
  • Connected them through MCP to Jira, Salesforce, GitHub, and Figma to validate drafts automatically.

Outcome

Drafting time dropped from one week to one day per feature.

Web Reviewer: online documentation review

Product owner and sole developer · Used by internal stakeholders

Challenge

Stakeholders reviewed documentation offline in Word files on OneDrive. The external vendor solutions we evaluated would have cost $10,000 a year.

What I did

Outcome

Built in-house instead, avoiding $10,000 a year in vendor costs.
